# Diagramas UML

## Como renderizar

Los archivos `.puml` se renderizan con **PlantUML**.

### Opcion 1: Online (recomendado)
1. Ir a https://www.plantuml.com/
2. Pegar el contenido del archivo `.puml`
3. Descargar como PNG

### Opcion 2: Extension VS Code
1. Instalar "PlantUML" extension
2. Abrir el `.puml`
3. Alt+D para previsualizar

### Opcion 3: draw.io
Los `.puml` se pueden importar a https://app.diagrams.net/
